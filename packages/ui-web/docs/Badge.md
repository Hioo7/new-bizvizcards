# Badge

A short status label. `tone` maps to the theme's semantic colors
(`neutral` | `primary` | `info` | `success` | `warning` | `error`); `outline` for
a lighter treatment; `icon` for a small leading glyph.

```tsx
<Badge tone="success" icon={<Check className="h-3 w-3" />}>Verified</Badge>
```
